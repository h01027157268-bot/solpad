# 教程：把 SolPad 部署到 devnet 并接通真实数据

全程 **$0**，**不需要 Linux**，**不需要装 git**，**不需要装 Solana CLI**。
你只需要一个 GitHub 账号和一个浏览器。

> 为什么不需要本地工具链：`cargo build-sbf`、`anchor test`、`solana-verify`
> 这些只有 Linux 能跑，全部交给 GitHub Actions（公开仓库免费无限时长）。

---

## 总览

| 步骤 | 在哪做 | 花多久 | 花多少钱 |
|---|---|---|---|
| 1. 建公开仓库 + 上传代码 | 浏览器 | 5 分钟 | $0 |
| 2. 跑 `devnet` workflow | 浏览器 | 812 分钟 | $0 |
| 3. 记下程序 ID | 浏览器 | 10 秒 | $0 |
| 4. `npm run connect -- <程序ID>` | 你的电脑 | 10 秒 | $0 |
| 5. `npm run dev` 看到真实数据 | 你的电脑 | 1 分钟 | $0 |
| 主网（等你有钱再做） | 浏览器 | 10 分钟 | 一次性押金 ~3 SOL（可退） |

## 第 1 步：建公开仓库并上传代码（不用 git）

### 1.1 准备压缩包

桌面上已经有我打好的包：

```
C:\Users\<你>\Desktop\solpad-github-<时间戳>.zip     （约 240 KB，84 个文件）
```

里面**没有** `node_modules`、没有构建产物、**没有任何私钥**（我验证过）。
以后代码有改动，重新生成一次即可：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/make-github-zip.ps1
```

### 1.2 建仓库

1. 打开 https://github.com/new
2. **Repository name**：`solpad`
3. 选 **Public**  必须公开，否则免费 Actions 额度只有 2000 分钟/月，而且拿不到"已验证源码"徽章
4. **不要**勾选 Add a README / .gitignore / license（我们自带）
5. 点 **Create repository**

### 1.3 上传

1. 把桌面的 zip **解压**，进到解压后的文件夹，`Ctrl+A` 全选里面的内容
2. 在刚建好的仓库页面点 **uploading an existing file**（或 Add file  Upload files）
3. 把选中的内容**拖进**浏览器窗口
4. 下面 Commit changes 里随便写一句，点 **Commit changes**

> 如果 GitHub 网页上传因为文件多而卡住，装一个 GitHub Desktop
> （https://desktop.github.com/）也能拖文件夹，效果一样。

上传完后，仓库首页应该能看到这些目录：
`app/`、`programs/`、`scripts/`、`docs/`、`.github/`、`Anchor.toml`、`README.md`、`LICENSE`、`SECURITY.md`

## 第 2 步：跑 devnet workflow（自动部署）

1. 仓库页面顶部点 **Actions**
2. 第一次会提示启用，点 **I understand my workflows, go ahead and enable them**
3. 左侧列表点 **devnet**
4. 右边点 **Run workflow**  分支选 `main`
   - `fee_sol`：发币手续费，默认 `0`（免费发币）
   - `treasury`：留空 = 用你仓库里配置的金库地址
5. 点绿色的 **Run workflow**
6. 等 812 分钟。它会依次做完：

```
cargo test --lib                      31 个单元测试（我不想让没测过的代码上线）
anchor build                          编译成链上程序
anchor test                           起本地验证器跑集成测试
anchor deploy --provider.cluster devnet    部署到 devnet（测试网 SOL 是免费领的）
solana airdrop 1 <你的金库>            给金库打 0.001 SOL 让它可以收钱
node app/scripts/init-config.mjs ...  初始化平台配置，把 1% 钉到你的金库
```

全部点绿之后，页面下方会有一份 **Summary**，里面有：

```
### deployed
program id: `xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
explorer:   https://explorer.solana.com/address/xxx?cluster=devnet
treasury:   EYB8XKsysDpSkK4PdBg4Rx3EMqY5NJ1LGfmvUdiKkqaQ
```

**那个 `program id` 就是你要的东西，复制它。**

在这个页面底部还能下载两个 artifact：
- `devnet-idl`  `launchpad.json`（前端要用的接口描述）
- `launchpad-build`  IDL + 编译好的 `.so`

## 第 3 步：一条命令接通前端

拿到程序 ID 后，在项目目录里：

```bash
cd app
npm run connect -- <你的程序ID> "C:\下载目录\launchpad.json"
```

这条命令会做三件事（你可以自己看 `app/scripts/connect.mjs`）：

1. 把 IDL 复制/更新到 `app/src/lib/solana/idl.json`，并把里面的地址改成你的程序 ID
2. 把 `NEXT_PUBLIC_PROGRAM_ID=<程序ID>` 写进 `app/.env.local`（这个文件不会被提交）
3. 跑一次 `gen-idl --check`，确认 IDL 和链上源码还是一致的

现在启动：

```bash
npm run dev
```

打开 http://localhost:3000  首页的曲线、成交量、前十榜、奖池**全部变成链上真实数据**。

## 第 4 步：验证 1% 真的进了你的金库

1. 在网站上连钱包（右上角 **Connect**），用 devnet 钱包
2. 去 `/create` 发一个币，或者买一笔已有的币
3. 打开 https://solscan.io/account/EYB8XKsysDpSkK4PdBg4Rx3EMqY5NJ1LGfmvUdiKkqaQ?cluster=devnet
4. **每笔交易后余额都会增加**，这就是那 1%

想从命令行确认：

```bash
solana balance EYB8XKsysDpSkK4PdBg4Rx3EMqY5NJ1LGfmvUdiKkqaQ --url devnet
```

链上证据：每笔 `buy` / `sell` 交易的 instruction 里都有一笔
`transfer` 到 `Config.treasury`，而 `Config.treasury` 就是初始化时写进去的
`EYB8...`。程序里那一行是：

```rust
transfer_lamports(&buyer, &treasury, breakdown.vault, None)?;   // vault = 1%
```

目标账户被 `#[account(mut, address = config.treasury)]` 钉死，**任何人都改不了**。

## 常见问题

**Q：`solana airdrop` 失败 / 说 rate limited**
devnet 水龙头有时限流。等几分钟再点一次 **Re-run failed jobs**，或者去
https://faucet.solana.com 手动给部署钱包打 1 SOL。
只要 `airdrop` 那一步失败，后面的 `init-config` 也会失败补上 SOL 重跑即可。

**Q：每次跑 workflow 程序 ID 都变**
因为每次 CI 都是全新的环境，Anchor 会生成新的程序密钥对。想固定地址：
把第一次生成的 `target/deploy/launchpad-keypair.json` 内容存成仓库秘密
**Settings  Secrets and variables  Actions  New secret  `PROGRAM_KEYPAIR`**，
之后每次都会用同一个地址。

**Q：`init-config` 报 `treasury ... needs at least 0.001 SOL`**
金库余额不够免租额。手动补：`solana airdrop 1 EYB8...` ，或在 workflow 里
把 `treasury` 那个输入框填成别的地址重跑。

**Q：前端显示 `Program not deployed`**
`.env.local` 里的 `NEXT_PUBLIC_PROGRAM_ID` 没写进去，或者没重启 dev server
（改完 `.env.local` **必须重启**）。

**Q：我想改前端代码，怎么让线上也是新的？**
前端和链上程序是分开的。前端可以白嫖 Vercel（Free 套餐）：
把仓库导入 Vercel，环境变量填 `NEXT_PUBLIC_PROGRAM_ID` 和
`NEXT_PUBLIC_TREASURY`，点 Deploy 就有公网地址。

**Q：主网什么时候能上？**
等你有 ~3 SOL（一次性押金，`solana program close` 可退）。步骤写在
`scripts/deploy-mainnet.md`，跑完再用 `.github/workflows/verify.yml`
把源码验证发上链，Solscan / Solana Explorer / SolanaFM 就会显示
**verified build**（也就是"全平台开源状态"）。

## 安全提醒（别跳过）

- `SECURITY.md` 顶上写着 **not audited**，在主网放过用户资金前请找人审计
  （重点看 `board.rs` / `round.rs` / `fees.rs` / `trade.rs` / `round_ix.rs`）
- 主网的金库请换成 **Squads 多签**，别用单个热钱包
- `keys/treasury.json` 是私钥，**不要提交、不要发群里**，离线备份两份
